Overview

ShipSpace-GA generates conceptual 3D internal arrangements of ships. It places functional compartments inside a hull for six vessel families. Each layout starts from a sampled brief of main dimensions and compartment volumes.

Every arrangement is stored as a voxel grid and as a spatial graph. Each zone of the ship becomes a node labelled with its compartment. Zones that touch are joined by edges.

We release a dataset of 50,000 generated arrangements with fixed train, validation and test splits. We compare it with 23 real references. These are general arrangements reconstructed from real ships. The repository holds the generator and the tools to validate and evaluate it.

    How the generator works

    The figure shows the workflow from the paper. The list below maps each stage to its module in the code.

    1. Sample the brief

      Draws the ship type, the main dimensions and the compartment volume budgets.

      ship_params.py

    2. Fit the hull

      Picks a hull template for the family and scales it to the sampled size. A superstructure is added on deck.

      hull_mask.py

    3. Subdivide

      Bulkheads, decks and side zones split the hull into zones.

      bulkhead_placement.py

    4. Assign functions

      Places fixed functions first, like steering gear and the engine room. Greedy assignment fills the remaining zones. Repair and refinement follow.

      compartment_assignment.py

    5. Encode

      Builds the spatial graph and the 64 × 32 × 32 voxel grid.

      graph_builder.py

    6. Check and package

      Runs the quality checks. Accepted samples go into train, validation and test shards.

      dataset_builder.py

    Parameter ranges, zone eligibility and the assignment rules are in the generator specification. The acceptance checks are in the QC summary.

    What each sample contains

    Each sample is a spatial graph in PyTorch Geometric format. Its voxel fields are stored on the same object. Shards hold up to 500 samples each.

    Spatial graph

    x
    19 geometric features per zone
    y
    Compartment class per zone
    edge_index
    Zones that touch, stored in both directions
    edge_attr
    7 features per edge for the centroid offset and the edge type
    cond
    16 conditioning values for ship type, main dimensions and programme

    Voxel grid

    voxel_labels
    Compartment class per cell on a 64 × 32 × 32 grid
    voxel_hull_mask
    Occupied envelope of the ship
    zone_node_mask
    Graph node that owns each cell
    companion
    Compact record per sample, loaded on request

    Field layouts, class IDs and metadata are in the dataset guide.

    Validation against real ships

    The validation tool compares a generated dataset with the 23 real references. It runs two comparisons. The first uses every stored spatial graph as generated. The second re-extracts 833 arrangements per family as connected-compartment graphs. This is the same extraction used for the real references.

    Results for the published dataset are in the paper.

    Engineering evaluator

    A separate evaluator computes calibrated whole-ship quantities for existing arrangements. It returns LCG, KG and an adjacency cost. It can also solve the equilibrium trim and a GM corrected for free surface. See the engineering guide.

    Scope

    Every released sample passes the production checks of the generator. These checks enforce the encoded early-stage design rules. Each sample is a conceptual layout for design-space exploration.

    Similarity measures reported by the validation tool
    MeasureWhat it compares
    Label JSDHow often each compartment class appears
    KS testsZone and edge counts, LCG, KG, GM and programme fractions
    MMDGraph structure through degree and clustering distributions

    CoverageShare of real references with a close generated neighbour in design-parameter space

    Get started

    Install

    Python 3.10 or newer.

    git clone https://github.com/kodendaal/ShipSpace-GA.git
cd ShipSpace-GA
pip install -r requirements.txt

    Generate a small dataset

    Ten arrangements per family, written to data/test_run.

    python generate.py --out data/test_run --per-type 10 --workers 6

    Compare with the real references

    Writes metrics, per-family reports and comparison figures. The full dataset needs about 10 GB of RAM.

    python validate.py --dataset data/test_run --out validation_test --per-type 10

    Load the published dataset

    Download the dataset from Zenodo and place it at data/dataset_v1.

    import sys
sys.path.insert(0, "src/data_generator")
from dataset_builder import load_split

graphs = load_split("data/dataset_v1", "train")
g = graphs[0]
